1. 验收概述

验收目的：确认 Yulux Sign 官网已按实施文档完成全部页面、模块、文案、图片占位及 SEO/GEO 优化，满足需求方可上线使用的标准。

验收范围：

  • 页面与路由：共 27 个有效路由（含 Gallery 分页）
  • 功能模块：导航、定制器、询价表单、购物车 Demo、FAQ 手风琴等
  • 内容：对照 xlsx 文案规划与 content/*.ts 源文件
  • SEO：Meta 标签、结构化数据、语义化 HTML、内链
  • GEO：Generative Engine Optimization，面向 AI 搜索/问答引擎的可引用性

验收方式：逐项勾选本报告检查项 → 填写通过/不通过/备注 → 双方签字确认。

如何使用本报告：左侧导航跳转至对应章节；每项前的复选框会自动保存在浏览器本地（localStorage），刷新不丢失。建议验收人打开网站与报告并排操作。

15.3 操作步骤（逐页 SEO 验收）

  1. 打开目标页面 → 右键「查看网页源代码」
  2. 搜索 application/ld+json，复制 JSON 至 Schema Validator
  3. 确认 0 Error（Warning 记录备注）
  4. 在 Chrome DevTools → Lighthouse → SEO，目标分数 ≥ 90
  5. 确认页面 H1 唯一，FAQ 可见内容与 FAQPage schema 一致
